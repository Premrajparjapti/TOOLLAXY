About Color Formats

  • HEX - Hexadecimal format used in web design (e.g. #RRGGBB)
  • RGB - Red, Green, Blue values (0-255 each)
  • HSL - Hue (0-360), Saturation (0-100%), Lightness (0-100%)
  • CMYK - Cyan, Magenta, Yellow, Key/Black percentages for print
  • Changes in any format will automatically update all other formats
