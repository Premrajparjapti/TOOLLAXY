About URL Encoding

  • URL encoding converts special characters to a % followed by two hexadecimal digits
  • Spaces become %20 or + in query strings
  • Reserved characters like :, /, ?, #, etc. have special meanings in URLs
  • Non-ASCII characters are encoded using UTF-8 before percent-encoding
  • Use encoding for query parameters and decoding to read encoded URLs
